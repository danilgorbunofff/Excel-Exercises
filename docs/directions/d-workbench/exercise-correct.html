Exercise 1 of 24 in Totals

Adding up a column is the most common job in a report. SUM does it in one step, and the total updates when a number changes.

What you need to do

  1. Type a formula in B6.
  2. Use SUM with the range B2 to B5.
  3. Press Enter.

This exercise checks that you use SUM, point at the cells, and get the right total.

Need help?

Hint 1

One function adds a whole range of cells.

Hint 2

SUM takes a range written as the first cell, a colon, then the last cell.

Show the answer

The answer is =SUM(B2:B5). Opening this marks the exercise as solved with help.
