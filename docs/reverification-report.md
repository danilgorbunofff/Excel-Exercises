# Reverification report: exercises, grading and task logic

Date: 2026-11-16. Brief: `docs/exercise-reverification-prompt.md`. Scope: the working tree as it stood, with phases 1 to 3 of the difficulty and pools plan uncommitted. That is 128 track exercises in 23 tracks, 56 daily tasks, and 50 mock tasks in 5 PRO sets plus the free sample. The brief's 118, 30 and 3 were out of date. Nothing was committed.

Ground truth is Microsoft Excel 16.109 on this Mac, driven by JavaScript for Automation (`tools/lib/excel-bridge.ts`). The Mac's region is en_CZ (decimal comma). Excel follows the region, and scripts cannot switch its separators. So a case that turns text into a number, or a number into text with a format code, is marked "needs an en-US Excel check" instead of being trusted.

Refusals are in `tools/audit/variant-skips.json`.
- Grader, matching Excel: IFS with array tests works per cell; AGGREGATE options 0, 1, 4 and 5 keep error values; INDEX on a 2-D range without a column number gives `#REF!`.
