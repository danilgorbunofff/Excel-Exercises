## Watching is not the same as doing

A video makes a formula look easy, because someone else is doing the thinking. The next day, facing an empty cell, most of it is gone. You learn a formula by writing it, getting it wrong and fixing it.

## Try first, then read

Start each new function with a small task before reading the full explanation. Even a failed attempt helps, because you then read the answer looking for what you missed.

## One function at a time

Learn a function on its own first, with a small sheet. Combine it with others only once you can write it without looking. Most long formulas are short ones nested together.

## Use realistic data

Practise on lists that look like work: orders, invoices, staff, stock. Real-looking data brings the real problems, such as blanks, text numbers and spaces, and you learn to handle them early.

## Get instant feedback

Knowing straight away whether an answer is right stops you from practising a mistake. The exercises on this site check each answer as you type and give a hint when you are stuck.

## Come back later

Redo a task a day later, then a few days after that. Each time it feels harder than expected, and each time it sticks better. The [progress page](/progress/) shows which exercises are due for review.

## Read the error

An error message is information. `#N/A` means no match, `#VALUE!` means the wrong type, `#REF!` means a reference was deleted. Read [how to read a formula error](/articles/reading-formula-errors/) once, and errors stop being a dead end.

## A little every day

Fifteen minutes a day beats two hours on a Sunday. The [daily exercise](/daily/) gives you one task a day, the same for everyone, and keeps a streak.

## Follow an order

Functions build on each other. References come before lookups, and IF comes before IFS. The [learning tracks](/exercises/tracks/) put the exercises in a sensible order, so each one uses what the last one taught.
