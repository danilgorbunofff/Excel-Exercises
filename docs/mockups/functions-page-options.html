Totals and averages

Total a range, and find the average, largest and smallest values.

SUMAdds numbers in cells and ranges.=SUM(number1, [number2], ...)
AVERAGEReturns the mean of a range of numbers.=AVERAGE(number1, [number2], ...)
MAXReturns the largest number in a range.=MAX(number1, [number2], ...)
MINReturns the smallest number in a range.=MIN(number1, [number2], ...)
SUMPRODUCTMultiplies matching values in ranges and adds the results.=SUMPRODUCT(array1, [array2], ...)
SUBTOTALTotals, counts or averages a range, picked by a function number.=SUBTOTAL(function_num, ref1, [ref2], ...)
AGGREGATETotals a range by a function number, with options to skip errors.=AGGREGATE(function_num, options, ref1, [ref2], ...)

Count cells

Count numbers, filled cells, empty cells and rows that match.

COUNTCounts the cells that hold numbers.=COUNT(value1, [value2], ...)
COUNTACounts the cells that are not empty.=COUNTA(value1, [value2], ...)
COUNTBLANKCounts the empty cells in a range.=COUNTBLANK(range)
COUNTIFCounts the cells that meet one condition.=COUNTIF(range, criteria)
COUNTIFSCounts the rows that meet every condition.=COUNTIFS(criteria_range1, criteria1, [criteria_range2, criteria2], ...)

Choose between results

Show one result or another, depending on a test.

IFReturns one value when a test is true and another when it is false.=IF(logical_test, value_if_true, [value_if_false])
ANDReturns TRUE when every test is true.=AND(logical1, [logical2], ...)
ORReturns TRUE when at least one test is true.=OR(logical1, [logical2], ...)
IFSReturns the result for the first test that is true.=IFS(logical_test1, value_if_true1, [logical_test2, value_if_true2], ...)
SWITCHMatches a value against a list of cases and returns the result for the match.=SWITCH(expression, value1, result1, [value2, result2], ..., [default])

AVERAGEIFAverages the cells that meet one condition.=AVERAGEIF(range, criteria, [average_range])

VLOOKUP

Lookup and reference

Finds a value in the first column of a table and returns a value from the same row, from a column you choose.

Syntax

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])

Arguments

lookup_valueRequiredThe value to find. It must be in the first column of the table. It can be a value or a cell that holds one.
table_arrayRequiredThe table to search. Its first column holds the values to find, and it must include the column to return from.
col_index_numRequiredWhich column of the table to return from, counting the table's first column as 1.
range_lookupOptionalFALSE or 0 finds an exact match. TRUE or 1 finds an approximate match. Leaving it out means TRUE.
